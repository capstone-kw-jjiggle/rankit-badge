## 📝 repo 소개
https://www.rankit.run/ 서비스의 뱃지 시스템입니다.   
pc환경에서 rankit 사이트에 접속하여 about에서 뱃지시스템의 사용법을 확인할 수 있습니다.

rankit에 등록된 유저의 아이디를 통해 유저의 정보를 받아와 깃허브 리드미에 사용할 수 있는 svg 이미지를 동적 생성합니다.

<br />

### ✨ 주요 기능

|뱃지 이미지 ( 예시 : jamooooong )|
|:---:|
|[![rankit-badge](https://badge.rankit.run/badge?name=jamooooong)](https://www.rankit.run)|
|깃허브 아이디, 자주쓰는 언어, 티어이미지, 전체유저등수, 점수가 표시됩니다.|
|뱃지 이미지 ( 등록되지 않은 유지 )|
|[![rankit-badge](https://badge.rankit.run/badge?name=없는유저)](https://www.rankit.run)|
|rankit에 등록된 유저가 없음을 표시|
